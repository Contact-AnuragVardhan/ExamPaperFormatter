A QUICK GUIDE

From Word file to ready exam.

Format Exam

Submit your teacher-authored .docx file with the correct subject and class. The formatter follows your school’s reference while preserving questions, wording, language, answers, and figures. Review the result before using it.

Check Exam

Checks the file against the same reference without changing your original exam. You receive a clear result, and an issues report when changes are needed.

When an exam needs changes

Download the issues report, fix the missing or inconsistent content in your original Word document, and upload it again. A report is clearly labeled as a report; it is not a formatted exam.

Using WhatsApp

Say Hi to open the main menu. Select Format Exam or Check Exam, choose your subject and class, attach a .docx document, and confirm. Say Hi at any stage to return to the main menu. A request already processing will still finish and send its result.

Cancellation and retry

A queued exam can be cancelled. Processing cannot be cancelled from this interface once it has started. A delivery retry sends the same saved file and does not format the exam again. If the processing status is unresolved, contact your administrator.
